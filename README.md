# Objective
To build a basic interactive dashboard using Power BI to show sales performance by product, region, and month using the Superstore dataset.

# Dataset
Superstore_Sales.csv  

# Dashboard Features

- Line Chart – Sales over Months (`Month-Year` format)
- Bar Chart – Sales by Region
- Donut Chart – Sales by Category
- Slicer – Region filter
- Conditional formatting and data labels for clarity

# Insights

1. The West region had the highest total sales, exceeding 700K, while the South region recorded the lowest sales.
2. Office Supplies contributed the highest percentage of total sales (36.4%).
3. January 2014 saw the highest monthly sales.
4. The Region slicer enables quick regional comparisons.

# Tools Used
- Power BI Desktop
- Excel / CSV for data input
